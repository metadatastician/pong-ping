  integer state or input. The evidence is implementation review plus tests.
* This is not a continuous or calibrated rigid-body simulation.
* The rendering is terminal based and manual input is turn based.
* No public release, cross-platform test matrix, external evaluation, or field
  validation is claimed.
* No safety-critical, vehicle-control, guidance, or weapons capability is
  claimed or intended.
