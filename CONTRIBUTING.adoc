= Contributing to Pong-Ping

The contributor guide is maintained at
link:./docs/contributing.adoc[docs/contributing.adoc]. Before proposing a
change to the reversible kernel, preserve the exact `step(c)`/`undo(c)`
round-trip invariant and add a test that exercises both directions.
